Vista de Procesos (Process View)

Dinámica de concurrencia, sincronización, control de aforo atómico de 8 cupos y contingencia presencial (QR y PIN).

sequenceDiagram autonumber actor Alumna as Alumna (App Movil) participant Front as Frontend (Next.js) participant API as Backend (Supabase API) participant DB as PostgreSQL (Transaccion) actor Docente as Docente (Panel) Note over Alumna, DB: Proceso Concurrente de Agendamiento (Tope 8 Cupos) Alumna->>Front: Selecciona clase presencial (viernes 18:00) y pulsa Reservar Front->>API: POST /reservas {userId, claseId} API->>DB: BEGIN TRANSACTION (Bloqueo atomico de fila) DB->>DB: SELECT cupos_inscritos, cupo_maximo FROM clase WHERE id = 12 alt Cupos < 8 y sin reserva previa DB->>DB: INSERT INTO reserva (id_usuario, id_clase, estado) DB->>DB: UPDATE clase SET cupos_inscritos = cupos_inscritos + 1 DB->>API: COMMIT TRANSACTION (Operacion exitosa) API-->>Front: HTTP 201 Creado {id_reserva: 104, cupos: 4/8} Front-->>Alumna: Toast Reserva Confirmada y actualiza aforo a 4/8 else Aforo Completo (8/8) o Reserva Duplicada DB->>API: ROLLBACK (Excepcion regla RN-01) API-->>Front: HTTP 409 Conflicto {error: Cupos agotados} Front-->>Alumna: Alerta Cupos Agotados (8/8) end Note over Alumna, Docente: Validacion Presencial con QR Dinamico o Contingencia Alumna->>Front: Solicita Pase Digital en recepcion Front->>Front: Genera token dinamico con hash y exp. 300s Alumna->>Docente: Presenta codigo QR en recepcion alt Camara fisica operativa en sala Docente->>Front: Escanea QR con lector web (MediaDevices) Front->>API: POST /asistencia/validar {token, metodo: qr_dinamico} API->>DB: INSERT INTO asistencia (id_reserva, fecha, metodo) API-->>Docente: Check verde Asistencia confirmada else Falla de hardware o baja luz Docente->>Front: Abre modal contingencia e ingresa PIN de 4 digitos Front->>API: POST /asistencia/validar {id_reserva, pin, metodo: manual} API->>DB: INSERT INTO asistencia (metodo: manual_profesor) API-->>Docente: Check verde Asistencia manual validada end

Código Mermaid (sequenceDiagram)

sequenceDiagram
    autonumber
    actor Alumna as Alumna (App Movil)
    participant Front as Frontend (Next.js)
    participant API as Backend (Supabase API)
    participant DB as PostgreSQL (Transaccion)
    actor Docente as Docente (Panel)

    Note over Alumna, DB: Proceso Concurrente de Agendamiento (Tope 8 Cupos)
    Alumna->>Front: Selecciona clase presencial (viernes 18:00) y pulsa Reservar
    Front->>API: POST /reservas {userId, claseId}
    API->>DB: BEGIN TRANSACTION (Bloqueo atomico de fila)
    DB->>DB: SELECT cupos_inscritos, cupo_maximo FROM clase WHERE id = 12
    alt Cupos < 8 y sin reserva previa
        DB->>DB: INSERT INTO reserva (id_usuario, id_clase, estado)
        DB->>DB: UPDATE clase SET cupos_inscritos = cupos_inscritos + 1
        DB->>API: COMMIT TRANSACTION (Operacion exitosa)
        API-->>Front: HTTP 201 Creado {id_reserva: 104, cupos: 4/8}
        Front-->>Alumna: Toast Reserva Confirmada y actualiza aforo a 4/8
    else Aforo Completo (8/8) o Reserva Duplicada
        DB->>API: ROLLBACK (Excepcion regla RN-01)
        API-->>Front: HTTP 409 Conflicto {error: Cupos agotados}
        Front-->>Alumna: Alerta Cupos Agotados (8/8)
    end

    Note over Alumna, Docente: Validacion Presencial con QR Dinamico o Contingencia
    Alumna->>Front: Solicita Pase Digital en recepcion
    Front->>Front: Genera token dinamico con hash y exp. 300s
    Alumna->>Docente: Presenta codigo QR en recepcion
    alt Camara fisica operativa en sala
        Docente->>Front: Escanea QR con lector web (MediaDevices)
        Front->>API: POST /asistencia/validar {token, metodo: qr_dinamico}
        API->>DB: INSERT INTO asistencia (id_reserva, fecha, metodo)
        API-->>Docente: Check verde Asistencia confirmada
    else Falla de hardware o baja luz
        Docente->>Front: Abre modal contingencia e ingresa PIN de 4 digitos
        Front->>API: POST /asistencia/validar {id_reserva, pin, metodo: manual}
        API->>DB: INSERT INTO asistencia (metodo: manual_profesor)
        API-->>Docente: Check verde Asistencia manual validada
    end
